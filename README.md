# TESTONE
Hackathon skeleton

to copy repoo:
cd path\to\TESTONE
git checkout main
git pull

HOW TO RUN:

install these...
python -m venv .venv
.venv\Scripts\python -m pip install flask pg8000 python-dotenv

FOR mac users......

python3 -m venv .venv
.venv/bin/python -m pip install flask pg8000 python-dotenv


then we all run:
.venv\Scripts\python app.py
